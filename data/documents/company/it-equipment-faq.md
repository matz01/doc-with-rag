# IT Equipment FAQ

*Owner: IT · Help: it-help@quillmoor.example or a ticket in Deskline*

**Which laptop will I get?**
Engineers receive a **MacBook Pro 14"**. Everyone else receives a **MacBook Air 13"**.

**How often are laptops replaced?**
Every **3 years**, or earlier if the device is faulty.

**Can I get an external monitor?**
Yes. Everyone can request one **27" monitor**. Engineers can request a second monitor.

**What do I do if my laptop is lost or stolen?**
Report it within 1 hour to security@quillmoor.example, as required by the IT Security Policy. If it was stolen, also file a police report **within 48 hours** and upload it to the Deskline ticket.

**How fast does IT answer tickets?**
The target first response time is **4 business hours**.

**What happens to my equipment when I leave?**
Return all equipment **within 5 working days** of your last working day. IT will send a prepaid courier box if you work remotely.

**Can I install my own software?**
Only software from the company catalogue in the self-service app. Request anything else through Deskline.
